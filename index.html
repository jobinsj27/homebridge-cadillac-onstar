Cadillac Homebridge

Use Apple Home to send commands to a supported Cadillac through your own Homebridge server. The optional Gmail presence feature reads forwarded Google Voice vehicle alerts and uses arrivals and departures to update a Home occupancy sensor.

This is an independent community plugin. It is not affiliated with Cadillac, General Motors, Google, or Apple. Each installation uses its own accounts and credentials.
